ss-truncate demo

Resize the window to see the responsive examples change.

ss-truncate="2"

Webflow gives you full visual control, but some small things still need code. Truncating long text to a fixed number of lines is one of them. With ss-truncate, you add a single custom attribute and the text is clamped neatly, with an ellipsis at the end, on every page that uses it.

ss-truncate="3" ss-truncate-tablet="2" ss-truncate-mobile="1"

This example shows three lines on desktop, two lines on tablet, and a single line on mobile. It is useful for blog cards, testimonials and CMS descriptions, where long text would otherwise break a carefully designed grid on smaller screens. Everything is controlled from Webflow's custom attributes panel, with no extra classes needed.

ss-truncate="1" ss-truncate-mobile="none"

On desktop this text is cut to one line, but on mobile the full text is shown, because the mobile breakpoint uses the value none to switch truncation off.
